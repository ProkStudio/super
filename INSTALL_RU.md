# TechPro — установка для Windows

## Что отдать другу

Из папки `release/`:

| Файл | Назначение |
|------|------------|
| **TechPro Setup 2.0.4.exe** | Установщик (рекомендуется) |
| **TechPro 2.0.4.exe** | Portable — без установки |

**Python и Playwright уже внутри установщика** — ничего отдельно качать не нужно.

## Шаг 1 — Установить TechPro

1. Запусти **TechPro Setup 2.0.4.exe**
2. Выбери папку, разреши ярлык на рабочем столе
3. Готово — первый запуск сразу работает

Portable: положи **TechPro 2.0.4.exe** в любую папку и запускай.

## Шаг 2 — MostLogin (для TikTok)

1. Установи **MostLogin** на том же ПК
2. Включи Local API (порт **30898**)
3. Создай профили браузера
4. В TechPro: **Профили** → **TikTok → Аккаунты** → войди в TikTok вручную → «Проверить вход»

## Шаг 3 — FFmpeg (только для уникализатора видео)

Для TikTok-комментинга **не нужен**.

Для YouTube-уникализатора: `ffmpeg.exe` в PATH или в `resources\bin\win\` внутри установки.

## TikTok — быстрый старт

1. Модуль **TikTok** (переключатель слева внизу)
2. **Автоматизация → Комментинг**
3. URL видео (полные или `vm.tiktok.com/…`)
4. Пул комментариев → профили → **Старт**
5. **Шпаргалка** (кнопка или **?** вверху) — подробная инструкция

## Частые проблемы

| Проблема | Решение |
|----------|---------|
| Антивирус блокирует | Добавь папку TechPro в исключения (нет цифровой подписи) |
| MostLogin не подключается | Клиент MostLogin запущен, API включён |
| WAF TikTok | vm-ссылки только через поле URL в TechPro, не в браузере |
| Python / Playwright красные в настройках | Пересобери установщик с `npm run build:win` (для разработчика) |

## Сборка (разработчик)

```bash
npm install
npm run build:win
```

Скрипт `bundle_python.ps1` скачает Python 3.11 embed + Playwright Chromium в `resources/python/` перед сборкой exe.

Артефакты: `release/TechPro Setup X.X.X.exe`, `release/TechPro X.X.X.exe`
