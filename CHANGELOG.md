# Changelog

## 2.0.6

- **TikTok AI:** генерация ответов через OpenRouter — живой стиль, homoglyph, фильтр конкурентов
- **TikTok AI:** защита от «протечки» промпта (английский мета-текст) + повторная попытка
- **TikTok:** дедуп ответов, просмотр перед комментом, меньше спама в тредах
- **TikTok:** параллельные профили, People-поиск, стабильнее MostLogin/CDP
- **Настройки:** тест TikTok-комментария, прокрутка вкладки API-ключей

## 2.0.5

- **Запуск:** окно «Что нового» с чейнджлогом при каждом старте (можно скрыть для версии)
- **Обновления:** компактное уведомление справа сверху, если доступна новая версия на GitHub
- **TikTok:** навигация только через TikTok — без Bing/Google при WAF
- **TikTok:** прогрев без лишних скроллов и выноса окон на передний план
- **Профили:** новый дизайн выбора — папки, таблица, чекбоксы, колонка @username
- **TikTok Automation:** профили выбираются на вкладке «Профили»
- **Терминал:** сворачиваемый лог автоматизации

## 2.0.4

- **TikTok:** навигация только через TikTok — убраны переходы на Bing, Google и другие поисковики при WAF
- **TikTok:** прогрев без лишних скроллов и выноса окон на передний план
- **Профили:** новый дизайн выбора профилей — папки, таблица, чекбоксы, колонка @username
- **TikTok Automation:** профили выбираются на вкладке «Профили», а не внутри автоматизации
- **Автообновление:** проверка GitHub Releases и установка без потери настроек
- **Терминал:** сворачиваемый лог автоматизации
